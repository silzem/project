# Project topic: Distribution of active Wildfires across Australia's states/territories
The project aims to visualise how active wildfires across Australia evolved during the last month and to analyse how the distribution differed spatially between states and territories.

## Repository Structure

This repository consists of
- data (not visible in GitHub as it is in .gitignore (file too large) -> can be downloaded from link below)
- notebook
- output

## Data Sources

Two sources were used for the data of this project:

1. An API to a csv for life fire data (VIIRS NPP Near Real Time) of NASA's FIRMS:
FIRMS (Fire Information for Resource Management System). NASA. Latest accessed 22 May 2026. https://firms.modaps.eosdis.nasa.gov/api/.
   
2. A boundary GeoPackage ("Main Structure & Greater Capital City Statistical Areas - 2021 - GeoPackage") of Australia's States/Territories from the Australian Bureau of Statistics:
Australian Bureau of Statistics. (Jul2021-Jun2026). Digital boundary files. ABS. Accessed 11 May 2026. https://www.abs.gov.au/statistics/standards/australian-statistical-geography-standard-asgs-edition-3/jul2021-jun2026/access-and-downloads/digital-boundary-files.
